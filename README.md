
# About the Project 🔍
Based on the challenge presented by the partner company, we developed a platform for "team feedback and climate & culture surveys". It provides a structured and transparent survey process to ensure the well-being of the whole team, promoting growth and motivation and reducing turnover rates in a company.

## Product Backlog

### Sprint 1
| Item | Priority | ID | User Stories |
|:----:|:--------:|:---:|:-----------:|
| HTML page, login and sign-up | 95 | 2 | "As a developer, I want to create an HTML page for user registration, with fields for name, email and profile, so the Admin can register new users efficiently." |
| Registration of different profiles | 90 | 3 | "As an Admin, I want to be able to register different user profiles (Admin, Leader, Team Member), to ensure the right permissions are assigned to each profile." |

### Sprint 2
| Item | Priority | ID | User Stories |
|:----:|:--------:|:---:|:-----------:|
| Interface to edit registered users | 80 | 5 | "As an Admin, I want to view, edit and remove users, to manage who has access to the system and their profiles in a centralized way." |
| Registration of evaluation questions | 50 | 11 | "As an Admin, I want to register evaluation questions in different formats (long text, single choice, multiple choice) to set up self-assessment and evaluation surveys." |

### Sprint 3
| Item | Priority | ID | User Stories |
|:----:|:--------:|:---:|:-----------:|
| Create and manage questions | 45 | 12 | "As an Admin, I want to create and manage question categories, so I can organize and classify the questions in the surveys." |
| Create and manage surveys | 40 | 13 | "As an Admin, I want to create and manage self-assessment and evaluation surveys with up to 20 questions, to collect feedback in a structured way." |


### Sprint 4
| Item | Priority | ID | User Stories |
|:----:|:--------:|:---:|:-----------:|
| Self-assessment dashboard | 25 | 16 | "As a user, I want to view a personal dashboard based on my self-assessment answers to track my progress and development areas." |
| Team member dashboard | 20 | 17 | "As a Leader, I want to view a dashboard of my team members to compare my evaluations with their self-assessments." |
| Admin dashboard | 15 | 18 | "As an Admin, I want to access a general dashboard that gives a complete view of the evaluations for comparative and managerial analysis." |
| Dashboard filters | 35 | 14 | "As a user, I want to apply date and category filters on the dashboards to view the information for the desired period or category." |
| PDF download | 10 | 19 | "As a user, I want to be able to save my evaluations as a digital document for future reference." |
